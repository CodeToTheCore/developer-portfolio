# Cornell Robertson: Developer Portfolio

My path from Pursuit fellow to software developer, shown as a timeline of every project from September 2023 to today.

**Live site:** https://cornell-robertson.vercel.app

## Add a project

Open `projects.js`, find the right era (or add a new one), and add an entry:

```js
{
  featured: true,                 // big card; leave out for a small chip
  name: "My New App",
  description: "What it does in one or two sentences.",
  tech: ["React", "Express"],
  repo: GH + "my-new-app",
  live: "https://...",            // optional
  team: true,                     // optional, shows a Team badge
}
```

## Run it locally

Open `index.html` in a browser. There's no build step.
